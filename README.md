# Personal Portfolio – Yahdih Essaad

A simple and clean personal portfolio website built with **React** and **Bootstrap**. It presents who I am, my training, my projects and how to contact me.

## Features

- Multi-page navigation with **React Router** (no page reload)
- Responsive design with **Bootstrap**
- Navbar available on every page
- "Page Not Found" route for unknown URLs
- Projects displayed dynamically from an array using `map()`

## Pages

| Page | Route | Description |
|------|-------|-------------|
| Home | `/` | Introduction and quick links |
| Experience | `/experience` | Training and skills |
| Projects | `/projects` | List of my projects |
| Contact | `/contact` | Email and GitHub links |

## Technologies

- React JS
- React Router DOM
- Bootstrap 5
- Vite

## Installation

```bash
npm install
npm install bootstrap react-router-dom
npm run dev
```

Then open the local URL shown in the terminal (usually `http://localhost:5173`).
